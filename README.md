# One-POS — media

Instagram, YouTube va boshqa tarmoqlarga joylanadigan **tayyor** rasm va videolar (ochiq).
Bu yerda faqat tayyor media turadi. Reja, matn va mijoz ma'lumoti bu repoga qo'yilmaydi.

- `narx/` — narx posti (karusel 3:4 va story)
- `reels/` — Reels / Shorts videolari va muqovalari

Manba va ish jarayoni — marketing repo (yopiq).
